# Spec: Feature #24 — Обрезка длинных названий товаров при печати чека 40x20мм

*Создано: 2026-05-14*
*Статус: analysis*
*Issue: https://github.com/shakirena/elektron/issues/24*

---

## Контекст

Страница `http://elektron/web/barcode/print2` (action `BarcodeController::actionPrint2`) отображает этикетки для термопринтера формата 40x20 мм. Шаблон `views/barcode/print2.php` выводит название товара `$res->idProduct->name` в `<span>` с уменьшенным размером шрифта при длине > 30 символов (`if (strlen($res->idProduct->name)>30) $size='9px';`).

Проблема: даже при шрифте 9px название может не уместиться в физические 40 мм ширины этикетки при большом количестве символов. Необходимо обрезать название + добавить многоточие, либо перенести на несколько строк с учётом CSS `word-wrap`.

---

## Functional Requirements

| ID | Требование |
|----|-----------|
| FR-1 | Название товара в шаблоне `views/barcode/print2.php` обрезается до MAX_CHARS символов, после чего добавляется `…` (U+2026) |
| FR-2 | MAX_CHARS = 28 символов при шрифте ≤ 9px на этикетке 40x20мм (рассчитано под моноширинный рендеринг термопринтера) |
| FR-3 | Обрезка применяется только в шаблоне печати — оригинальное значение `Product::$name` в БД не изменяется |
| FR-4 | Изменение затрагивает только файл `views/barcode/print2.php`, все остальные шаблоны (print.php, print_new.php) не изменяются |
| FR-5 | Короткие названия (≤ MAX_CHARS символов) отображаются без изменений, без добавления `…` |
| FR-6 | Логика обрезки корректно работает с многобайтовыми кириллическими символами (использовать `mb_strlen` / `mb_substr`) |

---

## Non-Functional Requirements

| ID | Требование |
|----|-----------|
| NFR-1 | Изменение не затрагивает БД: нет миграций, нет изменений модели |
| NFR-2 | Изменение не затрагивает контроллер `BarcodeController` |
| NFR-3 | Совместимость с PHP 7.4+ (mbstring extension доступен) |
| NFR-4 | Существующие unit-тесты не ломаются (нет регрессии) |
| NFR-5 | Шаблон `print2.php` остаётся читаемым — логика обрезки выносится во вспомогательную переменную, не inline в echo |

---

## Acceptance Criteria (из issue)

- AC-1: Название товара обрезается до максимальной длины, умещающейся в этикетку 40x20 мм
- AC-2: Обрезка происходит только при печати, оригинальное название в базе не изменяется
- AC-3: При необходимости добавляется многоточие (…), либо текст переносится в рамках допустимой области
- AC-4: Изменение применяется только к шаблону print2 (не к экранному отображению)
- AC-5: Все существующие этикетки с короткими названиями отображаются корректно

## User Stories

### Story #25: Обрезка длинного названия в шаблоне print2.php с добавлением многоточия

**Как** оператор склада,
**Я хочу** чтобы длинные названия товаров обрезались с добавлением `…` при печати этикетки 40x20мм,
**Чтобы** название помещалось в пределах этикетки и не выходило за её границы.

```gherkin
Given в базе есть товар с названием длиннее 28 символов (например, "Кабель USB Type-C 1.5м нейлон чёрный")
When оператор открывает http://elektron/web/barcode/print2 для печати этикеток
Then название товара отображается как "Кабель USB Type-C 1.5м нейло…" (обрезано до 28 символов + "…")
```

**Size:** S (≤ 1 день)
**Depends on:** нет

---

### Story #26: Корректное отображение коротких названий без обрезки

**Как** оператор склада,
**Я хочу** чтобы короткие названия товаров (≤ 28 символов) отображались без изменений при печати,
**Чтобы** не было случайного добавления многоточия там, где оно не нужно.

```gherkin
Given в базе есть товар с названием не длиннее 28 символов (например, "Кабель HDMI 1м")
When оператор открывает http://elektron/web/barcode/print2 для печати
Then название товара отображается полностью без добавления "…"
```

**Size:** S (входит в ту же реализацию, что #25 — отдельный тест-кейс)
**Depends on:** нет

## Технические заметки

Текущая логика в `views/barcode/print2.php` (строки 52-55):
```php
if (strlen($res->idProduct->name)>30) $size='9px';
else $size='12px';
echo "...<span style='font-size:$size !important'>".$res->idProduct->name."</span>...";
```

После изменения:
```php
$productName = $res->idProduct->name;
$maxChars = 28;
if (mb_strlen($productName, 'UTF-8') > $maxChars) {
    $displayName = mb_substr($productName, 0, $maxChars, 'UTF-8') . '…';
    $size = '9px';
} elseif (strlen($productName) > 30) {
    $displayName = $productName;
    $size = '9px';
} else {
    $displayName = $productName;
    $size = '12px';
}
echo "...<span style='font-size:$size !important'>" . Html::encode($displayName) . "</span>...";
```
